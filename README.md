# 水产养殖场（aqua_farm）

Spring Boot 3.3 + Vue3(Element Plus) 全栈种子仓，题材为淡水水产养殖场，湖蓝 #039BE5 主题，左侧塘口卡列表导航，塘口卡 + 水质三环 + 捕捞批次流水范式。

## 4 个业务模块与规则
1. **塘口**（pond）：塘号唯一、面积 > 0；只有「在养」可投放 / 可捕捞；废弃塘为终态，不可再做任何作业。
2. **鱼苗投放**（stocking）：只能投到在养塘，尾数与规格 > 0，成活率须在 0~100，投放后累加塘口存栏。
3. **水质检测**（water）：状态由服务端按溶氧与 pH 计算（溶氧 < 3.0 或 pH < 6.5 / > 9.0 判超标，溶氧 < 4.5 判预警），废弃塘不可检测。
4. **捕捞出塘**（harvest）：金额 = 斤数 × 单价由服务端计算，只能捕在养塘，出塘后扣减存栏，存栏不足则拒绝。
